Demo pubblica disponibile

Esplora un pacchetto disputa fittizio, un manifest visibile e un piccolo audit trail. Nessun dato di produzione, nessuna chiamata commerciale.

dispute-summary.json demo-export.zip Vedi accesso
ProdottoDemoAccessoFAQ

1. Caso già preparato

La demo usa una disputa Shopify fittizia per mostrare il flusso senza esporre dati reali del negozio.

2. File ispezionabili

Apri file JSON, controlla l’audit trail e scarica un piccolo export zip preparato per la visualizzazione pubblica.

3. Passo successivo pulito

Se la demo ha senso, la pagina accesso diventa il ponte verso il lancio o verso la runtime più avanti.

Cosa non fa la demo
  • Non crea dispute reali.
  • Non si collega a dati Shopify o Stripe di produzione.
  • Non invia prove ai circuiti carta.
  • Non sostituisce revisione legale.
