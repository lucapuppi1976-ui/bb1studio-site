# UI + Multilingua V2

Questo overlay aggiorna Agri App con:

- interfaccia più sobria e leggibile;
- copy più chiaro e meno tecnico;
- base multilingua front/back;
- selettore lingua nell'interfaccia;
- lingua salvata nel cookie `agri_locale`;
- lingua preferita salvata in `NotificationPreference.locale`.

Lingue incluse:

- Italiano (`it`)
- Español (`es`)
- English (`en`)
- Slovenčina (`sk`)
- Français (`fr`)
- Deutsch (`de`)
- Русский (`ru`)
- Magyar (`hu`)

Nota: questo overlay non contiene `package.json` né `package-lock.json`, così evita conflitti inutili con il branch live già stabilizzato.
