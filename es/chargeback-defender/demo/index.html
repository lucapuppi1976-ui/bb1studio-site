ProductoDemoAccesoFAQ

1. Caso ya preparado

La demo usa una disputa Shopify ficticia para mostrar el flujo sin exponer datos reales de la tienda.

2. Archivos que puedes revisar

Abre archivos JSON, revisa el audit trail y descarga un pequeño export zip preparado para vista pública.

3. Siguiente paso limpio

Cuando la demo encaje, la página de acceso se convierte en el puente hacia el lanzamiento o la runtime más adelante.

Qué no hace la demo
  • No crea disputas reales.
  • No conecta con datos de producción de Shopify ni Stripe.
  • No envía evidencia a redes de tarjeta.
  • No sustituye revisión legal.
